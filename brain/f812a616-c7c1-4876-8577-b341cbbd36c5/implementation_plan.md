# แผนการพัฒนา: การบันทึกประวัติการตั้งค่าใบเสนอราคาผูกกับลูกค้า

เป้าหมายคือการเพิ่มฟังก์ชันให้หน้าสร้างใบเสนอราคา (`quotations/new`) สามารถจดจำการตั้งค่าล่าสุดของลูกค้าแต่ละรายได้ เช่น ชื่อโครงการ, ประเภทใบเสนอราคา, รูปแบบการเข้าดำเนินการซ่อมบำรุง และจำนวนงวดการเบิกจ่าย เมื่อผู้ใช้เลือกตัวลูกค้า ระบบจะดึงค่าเหล่านี้มาแสดงอัตโนมัติ

## ส่วนที่ต้องแก้ไข

### 1. `src/lib/schema/salesCustomer.ts`
เพิ่มฟิลด์ลงใน Zod Schema และฟังก์ชัน `mapFirebaseToSalesCustomer` เพื่อรองรับการอ่านข้อมูลจากฐานข้อมูล:
- `defaultProjectName`: ชื่อโครงการล่าสุด
- `defaultQuotationType`: ประเภทใบเสนอราคาล่าสุด (trading, project, maintenance)
- `defaultMaintenanceVisits`: จำนวนครั้งการเข้าดำเนินการซ่อมบำรุง
- `defaultMaintenanceInstallments`: จำนวนงวดการเบิกเงิน

### 2. `src/app/(authenticated)/sales/quotations/new/page.tsx`
- **การโหลดข้อมูล**: ใน `useEffect` ที่คอยจับตาดูการเปลี่ยน `selectedCustomer` เพิ่มการเซ็ตค่า `projectName`, `quotationType`, `maintenanceVisits`, และ `maintenanceInstallments` หากลูกค้ามีค่าที่เคยบันทึกไว้
- **การบันทึกข้อมูล**: ในฟังก์ชัน `handleSaveDocument` เพิ่มการนำค่าที่ผู้ใช้กรอกปัจจุบันบันทึกลงไปใน `customerRef` ใน Firestore เพื่อให้จำค่าไว้ใช้ครั้งถัดไป
- **หน้าจองานซ่อมบำรุง**: ปัจจุบันมีฟิลด์ "เข้าดำเนินการ (ครั้ง/ปี)" และ "เบิก (งวด)" พร้อมคำนวณยอดรวมภาษีต่องวดอยู่แล้ว สิ่งที่ต้องทำเพิ่มคือแค่ผูกการบันทึกประวัติให้ทำงานได้ตามโจทย์

## การตรวจสอบ
- เมื่อเลือกลูกค้าที่มีประวัติ ข้อมูลช่องต่างๆ ต้องถูกเติมอัตโนมัติ
- เมื่อทำการกด "บันทึกร่าง" หรือ "ส่งขออนุมัติ" ข้อมูลที่กรอกล่าสุดจะต้องถูกอัปเดตไปที่ฐานข้อมูลของลูกค้า
