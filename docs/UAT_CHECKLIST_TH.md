# รายการตรวจรับระบบก่อนเริ่มใช้งานจริง (UAT)

สำหรับฝ่ายบัญชีและหัวหน้าแต่ละฝ่าย ใช้ตรวจว่าระบบทำงานถูกต้องตามงานจริงของบริษัท ก่อนเลิกใช้ระบบเดิม

**วิธีใช้เอกสารนี้**
- ทำตามทีละข้อด้วยข้อมูลจริงของบริษัท (หรือรายการทดลองที่ลบทิ้งได้)
- ติ๊ก ☐ เมื่อผลตรงกับ "ผลที่ถูกต้อง" ถ้าไม่ตรง ให้จดเลขที่เอกสารและสิ่งที่เห็นไว้ในช่องหมายเหตุ
- ทุกหน้ามีปุ่ม **?** มุมขวาบน อธิบายขั้นตอนของหน้านั้น

---

## 0. ก่อนเริ่ม (ผู้ดูแลระบบ)

| ☐ | ตรวจ | ผลที่ถูกต้อง | หมายเหตุ |
|---|---|---|---|
| ☐ | ตั้งค่า › ข้อมูลนิติบุคคล: ชื่อ ที่อยู่ เลขผู้เสียภาษี สาขา โลโก้ | ตรงกับ ภ.พ.20 และแสดงบนหัวเอกสารทุกใบ | |
| ☐ | ตั้งค่า › ผู้ใช้งาน: ทุกคนมีบัญชีและตำแหน่งถูกต้อง | แต่ละคนเห็นเมนูเฉพาะงานของตน | |
| ☐ | ตั้งค่า › รูปแบบเลขที่ | เลขที่เอกสารตรงกับที่บริษัทใช้ (ต่อจากระบบเดิมได้) | |
| ☐ | สำรองข้อมูล (`npm run backup:firestore`) | มีไฟล์ในโฟลเดอร์ backups | |

## 1. ย้ายข้อมูลจากระบบเดิม (ฝ่ายบัญชี) — เมนู นำเข้าข้อมูล Excel

| ☐ | ทำ | ผลที่ถูกต้อง | หมายเหตุ |
|---|---|---|---|
| ☐ | นำเข้าลูกค้า ผู้ขาย สินค้า (ไม่เลือก "ลงบัญชียอดยกมาสินค้า") | จำนวนรายการเท่าไฟล์ แถวที่ไม่สำเร็จมีเหตุผลบอก | |
| ☐ | นำเข้างบทดลองยกมา ณ วันก่อนเริ่มใช้ระบบ | ได้ใบสำคัญร่าง 1 ใบ เดบิต = เครดิต = ยอดในงบทดลองเดิม | |
| ☐ | อนุมัติลงบัญชีใบสำคัญยกมา (ผู้อนุมัติต้องไม่ใช่ผู้นำเข้า) | รายงาน › งบทดลอง ยอดยกมาตรงกับงบทดลองเดิมทุกบัญชี | |
| ☐ | นำเข้าลูกหนี้คงค้างรายใบ และเจ้าหนี้คงค้างรายใบ | ตารางกระทบยอด: ลูกหนี้ 1131 และเจ้าหนี้ 2111 ยอดต่าง = 0 | |
| ☐ | ตรวจสินค้าคงเหลือ | ตารางกระทบยอด: สินค้า 1141 ยอดต่าง = 0 (ถ้าไม่ 0 ตรวจต้นทุน/จำนวนยกมา) | |

## 2. งานขาย (ฝ่ายขาย + บัญชีตรวจ)

| ☐ | ทำ | ผลที่ถูกต้อง | หมายเหตุ |
|---|---|---|---|
| ☐ | ทำใบเสนอราคา → ส่งลูกค้า (พิมพ์ PDF และส่งลิงก์) | PDF ภาษาไทยครบ ไม่มีสระลอย/ตัดคำผิด ลิงก์เปิดได้จากมือถือ | |
| ☐ | แปลงเป็นใบสั่งขาย → อนุมัติ | ลูกค้าเกินวงเงินเครดิต ระบบไม่ให้อนุมัติ | |
| ☐ | คลังเบิกสินค้า พิมพ์ใบส่งของ | สต็อกลดตามจำนวนที่ส่ง | |
| ☐ | ออกใบกำกับภาษี + ใบวางบิล | เลขที่เรียงต่อเนื่อง ไม่ข้ามเลข · ข้อมูลผู้ซื้อครบตาม ม.86/4 (ชื่อ ที่อยู่ เลขผู้เสียภาษี สาขา) | |
| ☐ | บัญชีอนุมัติรายการ: Dr ลูกหนี้ / Cr รายได้ + ภาษีขาย | ยอดตรงใบกำกับ | |
| ☐ | รับชำระบางส่วน (ลูกค้าหัก 3%) | ใบเสร็จออกได้ ยอดค้างที่เหลือถูกต้อง ภาษีถูกหักคิดจากยอดก่อน VAT | |
| ☐ | ออกใบลดหนี้ 1 ใบ | ยอดค้างลดลง ภาษีขายเดือนนั้นลดลง | |
| ☐ | ขายหน้าร้าน 1 บิล (ถ้าใช้) | พิมพ์ใบเสร็จได้ ราคาบวก VAT ถูกต้อง สต็อกลด | |

## 3. งานจัดซื้อและคลัง

| ☐ | ทำ | ผลที่ถูกต้อง | หมายเหตุ |
|---|---|---|---|
| ☐ | เปิดใบขอซื้อ → ผู้อื่นอนุมัติ → สร้างใบสั่งซื้อ → อนุมัติ | ผู้ขอซื้ออนุมัติใบของตัวเองไม่ได้ | |
| ☐ | รับสินค้าบางส่วน แล้วรับส่วนที่เหลือ | สถานะใบสั่งซื้อ รับบางส่วน → รับครบ · ต้นทุนเฉลี่ยคำนวณใหม่ | |
| ☐ | บันทึกรายจ่าย (ตั้งเบิกจากใบสั่งซื้อ) + บันทึกใบกำกับภาษีซื้อ | ภาษีซื้อเข้ารายงานเดือนของใบกำกับ | |
| ☐ | จ่ายชำระ หัก ณ ที่จ่าย 3% | ออก 50 ทวิ อัตโนมัติ ยอดเข้ารายงาน ภ.ง.ด.3/53 เดือนที่จ่าย | |
| ☐ | โอนย้ายสินค้าระหว่างคลัง / ตรวจบัญชีคุมสินค้า | ยอดคงเหลือแต่ละคลังถูกต้อง | |

## 4. โครงการและงานบริการ

| ☐ | ทำ | ผลที่ถูกต้อง | หมายเหตุ |
|---|---|---|---|
| ☐ | สร้างโครงการ ตั้งเงินประกันผลงาน % และงวดงาน | มูลค่างวดรวม = มูลค่าสัญญา | |
| ☐ | ออกใบแจ้งหนี้งวด 1 | หักเงินประกันถูกต้อง ไม่ใช่ใบกำกับภาษี | |
| ☐ | รับเงินงวด 1 | ใบเสร็จเป็นใบกำกับภาษีด้วย (ม.78/1) ภาษีขายเข้าเดือนที่รับเงิน | |
| ☐ | เบิกของ/ค่าแรงผู้รับเหมาเข้าโครงการ | หน้าเทียบงบแสดงต้นทุนจริง | |
| ☐ | รับแจ้งซ่อม → ส่งให้ช่าง → ช่างเช็คอิน ปิดงานบนมือถือ | สถานะเปลี่ยนครบทุกขั้น ลายเซ็นลูกค้าบันทึกได้ | |

## 5. บัญชีสิ้นเดือน (ฝ่ายบัญชี)

| ☐ | ทำ | ผลที่ถูกต้อง | หมายเหตุ |
|---|---|---|---|
| ☐ | อนุมัติรายการบัญชีร่างทั้งหมดของเดือน | กล่อง "งานรอดำเนินการ" ไม่มีรายการบัญชีค้าง | |
| ☐ | รายงานภาษีขาย / ภาษีซื้อ | ตรงกับเอกสารที่ออก ส่งออกไฟล์ได้ | |
| ☐ | ภ.พ.30 / ภ.ง.ด.3 / ภ.ง.ด.53 | ยอดตรงกับรายงาน ใช้ยื่นได้ | |
| ☐ | กระทบยอดธนาคาร (นำเข้า CSV จากธนาคาร) | จับคู่รายการได้ ยอดคงเหลือตรง statement | |
| ☐ | งบทดลอง งบกำไรขาดทุน งบแสดงฐานะการเงิน | งบทดลองสมดุล ลูกหนี้/เจ้าหนี้ตรงกับบัญชีย่อย | |
| ☐ | ปิดงวด แล้วลองบันทึกเอกสารลงวันที่ในงวดที่ปิด | ระบบไม่ยอมให้บันทึก | |
